# CellScope 업데이트 내역

## 2026-10-28

### 처음 만든 기능

- 3D 세포 탐구 화면을 만들었습니다. 동물세포와 식물세포를 전환하고, 세포를 돌리거나 확대하면서 소기관을 살펴볼 수 있습니다.
- 소기관 목록, 선택 표시, 이름표, 정보 카드, "세포를 글로 읽기" 패널을 넣었습니다.
- 세포 앞면을 잘라 안을 보는 절단면 슬라이더와 단면 표시용 캡을 넣었습니다.
- 모형 현미경 시야(2D)와 초점 슬라이더, "10 µm (모형)", "축척 아님" 안내를 넣었습니다.
- 삼투 실험을 만들었습니다. 외부 농도를 0~600 mOsm/L로 바꾸고 물 입자, 부피, 내부 농도, 상대 팽압, 상태를 확인할 수 있습니다.
- 동물세포의 팽창·파열과 수축(쭈그러짐), 식물세포의 팽만과 원형질 분리를 각각 표현했습니다.
- 세포 분열 실험을 만들었습니다. 간기부터 세포질 분열까지 6단계를 넘기고, 단계 슬라이더로 세밀하게 조절할 수 있습니다.
- 4개 염색체(2쌍) 간단화 모형, 방추사, 핵막 변화, 두 딸세포가 만들어지는 장면을 넣었습니다.
- 분열 단계 순서 맞추기 연습을 넣었습니다.
- 여섯 개 미션을 만들었습니다. 예측 → 관찰 → 설명 순서로 진행하고, 틀리면 정답 대신 힌트를 보여 줍니다.
- 미션 완료 기록, 마지막 세포 종류, 보기 설정을 이 브라우저에 저장하도록 했습니다.
- 교사용 화면에 정답·해설 보기, 수업 장면 프리셋, 진행 기록 초기화, 빈칸 학습지 인쇄를 넣었습니다.
- 휴대폰·태블릿·데스크톱에 맞춘 반응형 화면과 하단 메뉴를 넣었습니다.
- 키보드 이동, 화면 읽기 안내, 동작 줄이기 설정을 넣었습니다.
- 오프라인에서도 열 수 있도록 PWA 설정과 앱 아이콘을 넣었습니다.
- 생물 계산은 모두 화면과 분리된 순수 함수로 만들었고, 삼투·분열·입자·소기관 데이터 단위 테스트를 넣었습니다.
- 실제 브라우저에서 탐구, 삼투, 분열, 미션, 교사용, 접근성, 세 화면 크기 스크린샷을 확인하는 테스트를 넣었습니다.

### 고친 점

- 삼투 실험이 한계에 도달한 직후 화면 숫자가 한 박자 늦게 멈추던 문제를 고쳤습니다.
- 태블릿 너비에서 상단 메뉴가 사라지고 하단 메뉴도 보이지 않던 문제를 고쳤습니다.
- 휴대폰에서 접이식 패널이 접혀도 내용이 보이던 문제를 고쳤습니다.
- 휴대폰에서 하단 메뉴가 실험 요약과 축척 안내를 가리던 문제를 고쳤습니다.
- 접힌 학습 내용을 열지 않고도 조작할 수 있던 테스트 동작을 실제 화면과 맞췄습니다.
- 처음 화면을 열 때 제목으로 초점이 이동해 건너뛰기 링크를 지나치던 문제를 고쳤습니다.
- 교사용 정답 보기 버튼과 진행률 막대의 화면 읽기 이름을 보완했습니다.
- 모형 안내 문구가 긴 화면에서 잘리지 않고 줄바꿈되도록 고쳤습니다.

### 배포

- GitHub 저장소 `wbmaker2/cellscope`에 앱을 올렸습니다.
- GitHub Pages에서 바로 사용할 수 있게 `https://wbmaker2.github.io/cellscope/`로 배포합니다.
- `main` 브랜치에 변경이 올라오면 자동으로 린트·단위 테스트·빌드를 거쳐 Pages에 배포되도록 GitHub Actions 워크플로를 추가했습니다.
- 휴대폰 홈 화면에 설치할 수 있는 PWA 설정과 오프라인 캐시도 그대로 유지됩니다.

### 눈이 불편한 깜빡임 개선

- 식물세포를 자동 회전할 때 투명한 세포벽·세포막·세포질이 겹쳐 보이며 깜빡이는 것처럼 보이던 문제를 줄였습니다.
- 자동 회전은 기본으로 꺼 두고, 필요할 때 화면 위의 '자동 회전' 버튼으로 켤 수 있게 바꿨습니다. 눈이 불편한 경우 바로 정지 상태로 볼 수 있습니다.
- 세포벽·세포막·세포질은 앞뒤 면을 모두 그려, 한쪽 면이 검게 비어 보이던 문제를 없앴습니다.
- 절단면이 0%일 때는 세포를 자르지 않도록 해, 식물세포 표면에 생기던 가로 줄무늬와 깜빡임을 없앴습니다.
- 동물세포에서 식물세포로 바꿀 때 구조 개수가 이전 숫자로 남던 문제를 고쳤습니다.
- 미션에서 예측을 확인한 직후 키보드 초점이 관찰 안내로 넘어가면서, 첫 소기관 선택이 씹히던 문제를 고쳤습니다.
- 소기관 이름표가 갑자기 튀지 않고 부드럽게 따라가도록 했습니다.
- 미션 3D 장면도 자동으로 돌지 않게 했습니다.
- 기존에 저장된 미션 진행 기록은 그대로 유지하면서 새 저장 형식으로 옮기고, 자동 회전 설정만 꺼지도록 했습니다.
